# War Room AI Team Workspace

Start here for coordinated project work.

Canonical project-management sources, in precedence order:

1. `.ai/shared/PROJECT_STATE.md`
2. `.ai/shared/ROADMAP.md`
3. `.ai/shared/DECISIONS.md`
4. `.ai/shared/WORKFLOW.md`
5. `.ai/manager/HANDOFF.md`
6. latest relevant role handoff

Role folders:

- `.ai/manager/`
- `.ai/builder/`
- `.ai/research/`
- `.ai/auditor/`

`AGENTS.md` remains useful technical/history context, but it is **not** the canonical roadmap, project state, workflow, or task ledger. If its older process/roadmap language conflicts with `.ai/shared/*`, the `.ai/shared/*` files win.

Do not start meaningful work without an assigned WR Task ID.
