## Objective
Upgrade The War Room workflow from V3 to V3.1 to reduce orchestration/CI overhead while preserving exact-head evidence, independent audit, Manager authority, and repository-as-memory discipline.

## Required upgrades
1. Allow multiple independent task-scoped chats for the same durable role when branches/surfaces do not conflict.
2. Add machine-readable blocker typing and explicit `user_action_required` state.
3. Require Auditors to publish their own audit PR before reporting `COMPLETE`.
4. Split CI into always-on governance checks and path-aware full product CI; `.ai/**`-only changes should not pay the full browser/product-test cost unless explicitly forced.
5. Add machine state-integrity checks for the active task registry and task specs.
6. Make `ACTIVE_TASKS.json` active-only; historical CLOSED work remains in task/report history rather than fast-path context.
7. Require external/provider tasks to specify provider-issued authority/scope evidence before implementation/audit.
8. Formalize post-merge main canaries for audited CI/test-harness/shared-infrastructure changes.
9. Strengthen atomic Manager reconciliation to one logical Git transaction whenever tooling supports it.

## Scope

- ranking/model logic/data
- `.ai/research/**`

- source custody contents/secrets

## Acceptance criteria
- V3.1 rules are canonical and concise.
- Current active-task registry contains no historical CLOSED tasks.
- Blocked/rework tasks expose blocker type and whether user action is currently required.
- State checker fails on registry/task-state contradictions and malformed active task metadata.
- Governance-only PRs receive governance CI without full product/browser test execution.
- Workflow/script/package/test-harness changes still trigger full CI.
- `force-full-ci` PR label can explicitly request the full matrix.
- Pushes to `main` containing infrastructure/test-harness changes automatically run the full matrix as the post-merge canary.
- Auditor charter requires report + handoff + immutable head + audit PR before `COMPLETE`.
- External-authority evidence is a first-class task requirement.
- Existing project/model governance is unchanged.

- Independent WR-052 audit required before merge.
