3. Auditor self-publication: report + handoff + immutable head + audit PR before `COMPLETE`.

5. Machine state-integrity checking.
6. Active-only `ACTIVE_TASKS.json`.
7. External/provider authority evidence contract.
8. Post-merge canonical-main canary for audited shared infrastructure/test-harness changes.
9. Strong atomic Manager reconciliation requirement.
