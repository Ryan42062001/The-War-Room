## Required security architecture

The pilot must preserve all of the following:

1. `classify` remains GitHub-hosted.
2. `governance` remains GitHub-hosted.
3. custody/protected-proof/credential-bearing workflows remain GitHub-hosted unless a future separately approved task says otherwise.
4. The self-hosted runner receives no B2/R2 custody credentials, provider credentials, or retained raw source bytes.
5. No arbitrary fork PR may execute repository code on the self-hosted runner.
6. Do not use `pull_request_target` to check out and execute untrusted PR-head code.
7. Use least-privilege workflow permissions; prefer `contents: read` and `persist-credentials: false` where compatible.
8. Do not expose machine secrets, local paths containing sensitive data, credential values, or reusable tokens in logs/artifacts.
