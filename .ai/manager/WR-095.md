## Required analysis

### A. Failure decomposition

Using only already-exposed 2018–2021 evidence, determine as far as the evidence supports:

1. whether the validation RMSE failure is concentrated in a small tail of extreme residuals or broadly distributed;
2. contribution of the largest candidate squared-error rows to total candidate SSE versus the primary baseline;
3. failure concentration by:
   - season;
   - position;
   - especially WR;
   - prior-volume / prior-performance regimes if derivable from already-published prediction evidence;
4. whether candidate MAE improvement + RMSE deterioration is consistent with better typical predictions but materially worse tail behavior;
5. whether WR regression is broad across the position or concentrated in identifiable subgroups / extreme rows;
6. candidate versus baseline rank behavior versus magnitude-error behavior;
7. development-to-validation drift that is visible without accessing unexposed outcomes;
8. whether the evidence indicates:
   - model-family misspecification;
   - loss-function / tail-sensitivity mismatch;
   - over-shrinkage or under-shrinkage;
   - position-specific instability;
   - feature instability;
   - baseline-blending opportunity;
   - sample-size / regime sensitivity;
   - or another defensible mechanism.

Do not overstate causality. Classify each conclusion as:
- VERIFIED FACT
- STRONG EVIDENCE
- INFERENCE
- SPECULATION
- UNKNOWN

### B. Post-hoc leakage guard

Explicitly identify every design choice that would be post-hoc if selected solely because it fixes a known 2020–2021 failure.

Do not silently convert the exposed validation set into a tuning set while continuing to call it validation.

Any new model-selection process must acknowledge that 2018–2021 is now design data.

### C. Candidate protocol families

Evaluate technically credible v2.1 directions without fitting them.

At minimum consider, where supported:

- robust-loss or tail-aware regression;
- deterministic prediction clipping / bounding policy;
- shrinkage or blending toward an accepted persistence/baseline forecast;
- position-specific protocol differences, especially WR;
- alternative regularization / model family;
- feature pruning or stability constraints;
- sample weighting;
- transformations that reduce catastrophic magnitude errors;
- explicit outlier/tail-risk controls;
- simpler baseline-plus-adjustment architecture.

These are investigation categories, not required conclusions.

For every serious candidate direction state:
- rationale tied to observed WR-081 failure evidence;
- what changes from WR-072;
- what stays fixed;
- overfitting risk;
- source/data implications;
- determinism/reproducibility implications;
- whether existing accepted source fields suffice;
- whether a new source/custody admission would be required.

Do not choose a new external data source merely because the old model failed.
