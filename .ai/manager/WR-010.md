## Manager preliminary evidence
These are starting hypotheses/evidence inputs, not conclusions R&D must accept:

1. FantasyPros publishes an objective preseason Draft Accuracy competition and a multi-year leaderboard. Current public evidence identifies Jody Smith as the 2023–2025 multi-year #1, with Sean Koerner and Joey Wright immediately behind him; 2025 single-year #1 was Seth Miller.
2. FantasyPros Draft Accuracy is evaluated using Half-PPR scoring, while the War Room's production value authority is PPR. Therefore a single overall accuracy leaderboard does not automatically prove the best PPR source for this application.
3. FantasyPros now exposes an official API with:
   - PPR consensus rankings
   - per-expert rankings
   - expert metadata
   - expert filtering by IDs
   - tiers / rank spread metadata
   - player metadata / IDs
4. FantasyPros API free access is described as non-production prototyping; personal production access is bundled with HOF. Published API terms/usage guidance include attribution and restrictions that may affect whether a private War Room integration is acceptable. Do not assume license compatibility without explicit review.

## Research questions
1. **Accuracy:** What is the strongest evidence-backed definition of "most accurate" for the War Room's PPR redraft use case?
2. **Source choice:** Is the strongest source a single expert, a top-N consensus, a recency-weighted cohort, an accuracy-weighted cohort, or the existing broader ECR?
3. **Historical stability:** Which experts/sources show multi-year consistency rather than one-season variance?
4. **PPR relevance:** How should Half-PPR accuracy results be translated, qualified, or supplemented for a PPR ranking authority?
5. **Availability:** Which top sources provide complete current preseason PPR rankings in a machine-readable or reliably accessible form?
6. **Automation:** What is the safest ingestion route: official API, another official feed/export, or controlled webpage parsing only as a fallback?
7. **Licensing/terms:** Is the proposed ingestion route permitted for this private/personal War Room use case? Identify material uncertainty; do not provide unsupported legal conclusions.
8. **Reliability:** How should automatic refresh fail closed so a partial, stale, malformed, or inaccessible source cannot silently corrupt the canonical 717-player board or ranking authority?
9. **Seasonality:** How often should source selection and ranking refresh occur (for example annual expert-cohort selection plus daily/on-demand preseason ranking refresh)?
10. **Value:** Would the proposed approach materially improve on the current Top-20/FantasyPros PPR ECR baseline enough to justify production work?

## Key methodological caution
Do not declare one expert "the most accurate PPR ranker" merely because that expert leads a Half-PPR multi-year leaderboard. The final recommendation must explicitly account for the scoring-method mismatch and the benefits/risks of consensus vs single-expert variance.
