## Required upgrades

1. **Schema-aware Manager transition helper**
   - Active Auditor activation must automatically populate missing `audit_target_task`, `audit_target_pr`, `audit_target_branch`, and `audit_target_sha` from one unambiguous frozen upstream target.
   - Ambiguous or incomplete targets fail closed.
   - Explicit caller-supplied pins must still match authoritative target state.

2. **Automated result-freeze verifier**
   - Add a deterministic read-only helper that verifies target PR/head, authorized path scope, report/manifest SHA-256, protected-evidence Git blob identities, protected workflow evidence, and exact-head CI.
   - Emit one deterministic Manager freeze packet.
   - Live/API unavailability is distinct from evidence contradiction.
   - Helper has no merge/Auditor-verdict authority.

3. **CI branch-bootstrap deduplication**
   - Detect branch/ref-creation pushes where the new branch points at a SHA already covered by accepted Governance.
   - Avoid duplicate expensive/bootstrap CI work without weakening Governance for new content.
   - Uncertainty fails upward to normal Governance/Full CI.

4. **Authority-driven protected dispatch**
   - For `authorized-wr081-scoring`, canonical main's `future_execution_authority` is the sole source of execution branch/head/consumer path/digest.
   - Remove manual identity-entry dependence from workflow dispatch.
   - Preserve exact live-head, reviewed-consumer, race, source/custody, publication, and fail-closed checks.

5. **Machine-readable terminal result summary**
   - Protected scoring emits a small privacy-safe result summary distinguishing at minimum:
     - `execution_status`
     - `result_terminal`
     - `decision_status`
   - Technical workflow success must not be confused with model-gate success.
   - No raw retained bytes or target data may be exposed.

6. **One-time authority-consumption receipt/check**
   - Protected scoring emits a deterministic receipt binding authorized head -> exactly one publication head, consumer identity, authority digest, run identity, and terminal result.
   - Subsequent Manager transition must fail closed unless the canonical authority is removed/consumed before a new protected execution is authorized.
   - Receipt must not authorize reruns by itself.
