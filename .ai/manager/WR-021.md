# WR-021 — Context-Enriched Preseason Shadow Model Validation

TASK ID: WR-021
ROLE: Research & Development (R&D)
STATUS: ASSIGNED / ACTIVE
DATE: 2026-09-09

## Objective
Run one bounded, research-only successor to WR-018 that tests whether genuinely preseason, rights-cleared context can materially improve a War Room-owned QB/RB/WR/TE projection model beyond the WR-018 naive baseline.

## Why needed
WR-018 showed that richer prior-season summary statistics alone did not reliably beat previous-season PPR/game. The unresolved hypothesis is materially different: preseason value may require information about age/experience, draft capital/rookie status, team movement, role/roster context, and availability rather than more tuning of the same historical-stat matrix.

## Verified starting state
Refresh actual `main` before branching. Manager WR-020 accepted WR-018 as `MORE EVIDENCE NEEDED`, merged PR #115, kept WR-D001 active, and authorized this research-only successor.

## Production authorization
NONE.

Do not modify production rankings, scoring, recommendations, tiers, VORP, board order, UI, ESPN sync, persistence, or canonical `.ai/shared/*`.

## Source / rights requirements
Create a new source/license manifest before model execution.

Candidate source families may include, only after exact rights/provenance verification:
- nflverse player metadata (age/birthdate, experience, draft round/number, rookie-year fields where available);
- nflverse season/weekly roster data for team movement or point-in-time roster context where historical semantics are defensible;
- WR-018 nflverse Player Summary Stats baseline inputs.

Do NOT use:
- PFF/PFF-derived data;
- systematic NFL Next Gen Stats / NFL Pro unless explicit rights for this modeling use are established;
- FantasyPros historical/API data for training or historical benchmarking without explicit rights;
- paid/private or scraped data with unclear terms;
- reconstructed hindsight depth/injury/role information.

Technical accessibility is not permission.

## Required experiment design
### 1. Preseason-defined cohort
Historical evaluation eligibility must be determined only from information available by the documented preseason cutoff for target season Y.

Do NOT require target-season games played, fantasy points, roster survival, or any Week 1+ outcome to decide whether a player belongs in the preseason evaluation cohort.

Rookies should be included when a defensible preseason roster/player record exists. Do not fabricate missing rookie context.

### 2. Targets
Separate the problem into defensible components:
- performance target: Full-PPR points per active/recorded game for players who actually record a target-season game;
- availability target: games active/recorded or an explicitly defined availability outcome if the admitted point-in-time sources support it;
- season-total PPR only if availability is modeled defensibly.

Players with zero/low target-season participation must be reported as an availability outcome, not silently dropped from the preseason cohort.

### 3. Baselines
Preserve WR-018's returning-player naive baseline: previous-season Full-PPR points/game.

For rookies/no-prior-history players, define a transparent preseason-only baseline (for example position + draft-capital/rookie-prior) before scoring and document it clearly.

Do not let a complex model win merely because the baseline cannot score rookies.

### 4. Context feature families
Only if point-in-time and rights-cleared:
- age at preseason cutoff;
- years experience;
- draft round / overall draft number;
- rookie indicator and rookie prior;
- team change from prior season;
- point-in-time roster status / preseason team;
- prior usage/production features from WR-018;
- role/depth/injury/availability information only if historical as-of semantics and rights are defensible.

If a source is season-final or otherwise hindsight-contaminated, exclude it.

### 5. Model-selection discipline
The 2022–2025 outcomes were already observed in WR-018. They are no longer pristine project-level holdouts.

Use earlier seasons (preferably 2018–2021 or another justified earlier rolling window) for feature/model selection and freeze the successor specification before re-scoring 2022–2025.

Treat 2022–2025 as confirmatory, not untouched, and state that limitation.

The 2026 prospective snapshot is the clean final test.

### 6. Models
At minimum compare:
- transparent returning-player naive baseline + transparent rookie baseline;
- a transparent regularized position-specific model;
- at most one higher-capacity challenger if sample size justifies it.

Do not continue hyperparameter/model proliferation if the simple model is not beaten.

### 7. Uncertainty
Do not treat repeated player-seasons as fully independent.

Report:
- per-season deltas;
- player-clustered bootstrap or another justified repeated-player-aware uncertainty estimate;
- pooled and position-level metrics.

## Evaluation metrics
At minimum:
- MAE/RMSE for Full-PPR points per active game;
- Spearman rank correlation;
- rank MAE;
- fantasy-relevant top-N overlap;
- availability error if modeled;
- season-total error if modeled;
- cohort coverage, including rookies and zero/low-participation players;
- position-level and season-level deltas versus baseline.

## Predeclared evidence gate
Classification may be `PROMISING — CONTINUE VALIDATION` only if the enriched model shows a material and reasonably stable improvement, not merely a tiny point estimate.

Primary gate for pooled returning-player performance:
- at least 2% pooled MAE improvement versus the WR-018 naive baseline;
- repeated-player-aware 95% uncertainty interval for MAE delta does not include a meaningful zero/worse result;
- pooled Spearman is not worse by more than 0.01;
- no major position shows a persistent material regression that would make a single pooled score misleading.

Rookie/availability gains may support continued validation, but cannot by themselves justify production if returning-player performance degrades materially.

If this gate is not met, return `MORE EVIDENCE NEEDED` or `DO NOT PURSUE`.
