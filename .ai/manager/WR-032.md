## Objective
Upgrade The War Room AI workflow without changing production draft behavior.

The War Room is the live fantasy-football draft assistant. This task must not modify The Chip Winner, Family Finance Hub, ECOG website, production rankings, recommendation logic, draft state, persistence, or ESPN synchronization.

## Required workflow changes

1. Add a permanent **Draft Strategy & Decision Intelligence Analyst** role for live draft-decision policy.
2. Keep the permanent team intentionally small: Manager, Builder, Draft Strategy, R&D, Auditor.
3. Treat roles as durable but chats as disposable; prefer fresh task-scoped worker chats.
4. Roll over Manager chats at milestone boundaries or earlier when context size harms speed/focus/state accuracy.
5. Add minimum-sufficient-context / context-budget rules using Fast Refresh by default.
6. Add concise role charters under `.ai/roles/` so fresh chats need only a short bootstrap prompt.
7. Keep handoffs concise and make them pointers to detailed evidence rather than encyclopedic copies.
8. Add a universal anti-loop rule: after roughly three materially different failed approaches without new evidence, stop and escalate.
9. Add temporary **Troubleshooting & Root Cause Engineer** escalation for difficult/cross-layer debugging; do not make it a permanent always-on worker.
10. Require Manager to assess whether **ChatGPT Work mode** would materially accelerate each new meaningful task.
11. Work mode must remain optional acceleration whenever normal chat can still complete the task. Work-credit exhaustion must not stall ordinary project progress.
12. Manager activation output must include execution-mode recommendation and fallback when Work mode is preferred/high-value.
13. Preserve existing Workflow V2 lifecycle, branch-advance classification, audit, merge, validation, and parallel-work safeguards unless explicitly superseded by V3.

## Work-mode classifications
- `STANDARD_CHAT`
- `WORK_MODE_PREFERRED`
- `WORK_MODE_HIGH_VALUE`

Any Work-preferred/high-value task must include a normal-chat fallback when feasible.
