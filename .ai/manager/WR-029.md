# WR-029 — Advanced Context Feature Enrichment / Source Feasibility

TASK ID: WR-029
ROLE: Research & Development (R&D)
STATUS: PLANNED / BLOCKED ON WR-027 MANAGER DISPOSITION
DATE: 2026-09-09

## Objective
Evaluate whether richer preseason-known usage, team-context, offensive-line, coaching/scheme, depth-chart and advanced-efficiency features materially improve the custom ranking engine beyond the WR-025 returning-player mean model, without violating source-rights, point-in-time or leakage rules.

## Why needed
The current engine already uses useful historical performance/opportunity signals, but user feedback correctly identifies several potentially high-value missing context families: offensive-line strength, offensive coordinator/staff environment, snap percentage, route participation/YPRR-like efficiency, and other detailed role/scheme indicators.

These features should be tested before the returning-player v1 specification is frozen. They must earn inclusion through chronological out-of-sample evidence; complexity alone is not sufficient.

## Dependency
HARD dependency on WR-027 Manager disposition because WR-027 determines the risk architecture and robust-regression policy that WR-029 must preserve as the benchmark.

WR-029 must complete before WR-028 Phase 2 — Returning-player projection specification freeze.

## Production authorization
NONE.

Do not inspect 2026 regular-season outcomes.
Do not modify the frozen WR-021 2026 snapshot or WR-023 protocol/manifest/gate.

## Candidate feature families

### A. Usage / participation — HIGH PRIORITY
Investigate rights-clean historical sources for:
- offensive snap percentage;
- offensive snaps/game;
- share of team offensive snaps;
- pass-play participation / route-participation proxy where defensible;
- routes run and true yards per route run (YPRR) only if exact route-denominator data and rights are verified;
- targets per route / pass-play participation;
- carries per snap;
- target share / carry share / opportunity share;
- red-zone and goal-line opportunity share;
- third-down / two-minute usage where point-in-time derivable.

Important: do not label a pass-play participation proxy as true routes run/YPRR unless the denominator really represents routes.

### B. Receiving / rushing efficiency — HIGH PRIORITY
WR/TE:
- yards per route or defensible route proxy;
- targets per route / participation;
- receiving yards per target;
- air-yards share / aDOT;
- WOPR / RACR-style opportunity-efficiency measures where reproducible;
- first-down rate;
- YAC/target or YAC/reception;
- TD-rate regression indicators;
- drops / drop rate only if rights and historical coverage are stable.

RB:
- rushing yards/game and per carry;
- success rate / EPA per rush;
- yards before contact / after contact if rights-clean and historically stable;
- explosive-run rate;
- goal-line share;
- targets/route or pass-play participation;
- receiving share / WOPR;
- efficiency-regression indicators.

QB:
- EPA/dropback;
- CPOE;
- pressure rate and sack rate under pressure where rights-clean;
- time to throw / pocket time where rights-clean;
- designed-rush and scramble share;
- red-zone passing/rushing usage;
- deep-target rate / air-yards profile;
- play-action/RPO/no-huddle/shotgun context if rights-clean.

### C. Offensive-line environment — HIGH PRIORITY BUT DERIVED
Do not depend on proprietary PFF-style OL grades.

Test open/reproducible proxies such as:
- team sacks allowed / dropbacks;
- pressure/hurry/hit rates if rights-cleared;
- rushing yards before contact proxies if available;
- short-yardage / goal-line rush success;
- adjusted-line-yards-style derived metrics from play-by-play;
- OL starter continuity / returning-snap share if historical roster/snap joins are defensible;
- aggregate experience / availability of likely starting OL only when point-in-time rosters/depth charts support it.

Treat OL quality as team context, not a causal individual-player grade unless evidence supports that interpretation.

### D. Coaching / scheme / staff context — HIGH VALUE, SOURCE-RISKED
Investigate:
- head-coach continuity/change;
- offensive-coordinator continuity/change;
- primary play-caller continuity/change where determinable;
- historical pass rate / pass rate over expected;
- neutral-situation pace / plays per game;
- no-huddle, shotgun, play-action, motion and RPO rates;
- RB/WR/TE target allocation;
- backfield committee concentration;
- personnel usage (11/12/21 etc.) only where the source is stable;
- historical coach/team tendencies as descriptive predictors, not causal coach grades.

Historical coordinator coverage and rights must be verified. Sparse or manually reconstructed coordinator data must not silently become a core feature.

### E. Team offensive environment — HIGH PRIORITY
- plays/game and pace;
- scoring drives / red-zone trips;
- team EPA/play;
- pass/run tendency;
- QB quality / QB continuity as context for RB/WR/TE;
- offensive-line proxies;
- target/carry concentration;
- vacated targets/carries from prior-season departures if point-in-time roster transactions can be reconstructed defensibly;
- team change / new-team indicator for players.

### F. Depth / competition / role transition — HIGH PRIORITY, POINT-IN-TIME SENSITIVE
- preseason depth-chart rank where a true pre-kickoff snapshot exists;
- teammate competition at the same role/position;
- returning target/carry competition;
- incumbent departure / target vacancy;
- rookie-veteran competition;
- expected starter status only if source timestamp proves it was known before kickoff.

Never use target-season Week 1+ role outcomes to reconstruct preseason roles.

### G. Age / career / physical context — ALREADY PARTIAL, RECHECK
- age and age curves by position;
- years of experience;
- draft capital;
- size / combine measures where rights-clean;
- multi-year trend / acceleration / decline;
- prior-year games and multi-year availability history.

### H. Injury / availability context — LIMITED
Historical injury reports may be explored only if source rights, coverage and point-in-time semantics are defensible.

Because current nflverse injury coverage has known gaps after 2024, do not create a core engine dependency on a source that cannot be maintained prospectively.

Fallback availability predictors may use prior games, snap continuity, age, role and historical missed-time patterns without calling the output a medical injury prediction.

### I. Schedule / opponent strength — SECONDARY ONLY
Preseason strength-of-schedule, dome/weather and opponent defensive quality may be evaluated only as secondary features because year-over-year opponent strength is unstable and should not dominate intrinsic player value.

## Source / rights review requirements
Before modeling, create a feature-source manifest with exact source, license/right basis, historical coverage, update cadence and point-in-time semantics.

Known promising open infrastructure to investigate includes nflverse Player/Team Stats, play-by-play, snap counts, rosters/depth charts, participation and FTN charting, but each family must be individually rights-reviewed because upstream provenance/licenses differ.

Do not use PFF/PFF-derived proprietary grades, paid/private data, ambiguous scraped datasets, or systematic NGS data unless the Manager accepts a documented rights basis.

## Experimental design
Use rolling-origin historical evaluation. For target season Y, every feature must be computable only from information available before Y regular-season kickoff.

Compare feature-family additions incrementally against the fixed post-WR-027 benchmark:
1. benchmark only;
2. + usage/snap features;
3. + advanced player efficiency;
4. + team/OL context;
5. + coaching/scheme;
6. + depth/competition;
7. selected combined model.

Do not keep a feature family merely because in-sample coefficients look interesting.

## Required metrics
At minimum:
- PPR/game MAE and RMSE;
- Spearman;
- position rank MAE;
- top-N overlap;
- tail/catastrophic over-rank frequency;
- repeated-player-aware uncertainty;
- per-position stability;
- calibration for any warning/risk outputs affected.

## Inclusion gate
A feature family may enter the Phase-2 v1 projection specification only if it provides repeatable chronological improvement or clearly useful warning calibration without material positional regression.

Features that are explanatory but not predictive should remain explanation-only rather than rank-driving.

Features with unstable coverage, source-rights problems, weak point-in-time semantics or excessive missingness must be excluded even if retrospective fit is attractive.
