## Required semantic contract

Freeze one unambiguous deterministic specification covering at least:

1. **Input decoding / CSV grammar**
   - text encoding and BOM behavior;
   - delimiter, quoting, escaping, embedded newline behavior;
   - line-ending normalization for parsing;
   - duplicate headers, blank headers, row-width mismatch, malformed quote handling;
   - whether surrounding whitespace is preserved or normalized.

2. **Null and empty-field semantics**
   - exact null-token set, case sensitivity, and whitespace treatment;
   - whether an empty unquoted field is null or empty UTF-8 string;
   - whether quoted empty string differs from unquoted empty field;
   - how literal tokens such as `NA`, `NaN`, `null`, `None`, or equivalents are classified.

3. **Canonical raw type vocabulary**
   - exact permitted type labels;
   - exact boolean lexical forms if booleans exist;
   - exact integer lexical grammar and width/range behavior;
   - exact decimal/floating lexical grammar, exponent handling, signed zero, and non-finite values;
   - exact date/datetime inference behavior, or an explicit rule that raw CSV does not infer those types;
   - exact UTF-8/string fallback semantics;
   - explicit leading-zero / identifier handling.

4. **Mixed-type inference / promotion**
   - deterministic column-wide promotion order;
   - interaction of nulls with type inference;
   - behavior for integer + decimal, numeric + text, boolean + numeric, date-like + text, overflow, malformed numeric tokens, and other mixed inputs;
   - no source-specific exceptions.

5. **Nullable semantics**
   - exact definition of `nullable`;
   - whether it is observed-nullability across the complete physical file or a type-level property;
   - empty-file/header-only behavior.

6. **Deterministic physical schema derivation**
   - complete-file scan requirements;
   - physical row-count definition;
   - ordered column preservation;
   - fatal conditions that prevent schema admission;
   - no sampling-based inference.

7. **Canonical typed-schema encoding/hash**
   - exact tuple/object shape;
   - field order;
   - UTF-8/JSON or equivalent canonical encoding rules;
   - newline/final-byte rules;
   - exact SHA-256 procedure;
   - version identifier included in or bound to the schema digest.

8. **Implementation authority / portability**
   - either freeze an exact parser/library/runtime/version plus all behavior-affecting options, or define lexical semantics fully enough that independent implementations reproduce the same result;
   - if an external parser is referenced, distinguish normative semantics from implementation convenience;
   - define fail-closed behavior for version drift or unsupported environments.

9. **Synthetic conformance corpus**
   - privacy-safe synthetic CSV vectors covering every edge above;
   - expected ordered `(column,type,nullable)` output and schema digest for each vector;
   - enough vectors for WR-068 to independently reproduce the contract without retained provider bytes.
