# WR-014 — Advanced Metrics Ranking Model Feasibility

TASK ID: WR-014
ROLE: Research & Development (R&D)
STATUS: QUEUED — NOT ACTIVE

## Objective
Determine whether The War Room could eventually replace or supplement expert-consensus ranking authority with a War Room-owned preseason player valuation model built from underlying football performance, opportunity, usage, and advanced-statistics data.

This is R&D only. No production ranking, scoring, recommendation, dataset, or API integration change is authorized.

## Why it is needed
The user proposed a materially valuable opportunity: rather than relying primarily on FantasyPros expert consensus, investigate whether the War Room can create its own rankings from objective advanced football statistics.

This would be a much larger architectural change than WR-010. It could create a differentiated ranking system, but only if the required data is legally usable, complete, reproducible, seasonally maintainable, and demonstrably predictive enough to beat or materially complement the current validated Top-20 FantasyPros PPR ECR baseline.

## Required research questions
1. What exactly should an internal ranking model predict: end-of-season PPR points, points per game, replacement-adjusted value, probability distribution, expected games played, or a composite draft-value target?
2. Which position-specific inputs are genuinely predictive rather than merely descriptive?
3. Which data sources are legally/operationally suitable for reproducible model development and production refresh?
4. Can open/licensable sources provide enough signal without depending on restricted proprietary providers such as PFF?
5. How should the model handle role changes, injuries, rookies, coaching changes, depth-chart movement, team environment, and small samples that historical stats alone miss?
6. Should the first viable architecture be a full replacement for ECR, an independent War Room projection/value model shown beside ECR, or a hybrid/ensemble that uses market/expert consensus as a prior?
7. What historical seasons and held-out validation design would prevent target leakage and same-season hindsight?
8. What metrics should determine whether the model is materially better than the current Top-20 PPR ECR baseline?
9. What source-refresh cadence and fail-closed validation would be required before draft season?
10. Can the model be explained enough that recommendation behavior remains auditable and trustworthy?

## Candidate source areas to investigate
R&D should independently verify current availability, licensing, completeness, and refresh behavior. Candidate areas include:
- nflverse / nflfastR play-by-play and player stats
- ffverse expected-fantasy-points / opportunity data
- nflverse snap counts, depth charts, rosters, player IDs, contracts, and available advanced pass/rush/receiving data
- NFL Next Gen Stats / NFL Pro public or licensed data where machine-readable use is permitted
- openly published FTN charting subsets or other explicitly licensed datasets
- weather, offensive line/team efficiency, coaching/pace/pass-rate data where rights and reproducibility are clear
- injury/availability and rookie/draft-capital sources where licensing permits

PFF must be treated as a restricted source unless explicit rights are established. Do not scrape, transcribe, or use PFF data to train a model merely because the user can view it.

## Model concepts to compare
At minimum compare:
- current FantasyPros Top-20 PPR ECR baseline
- open-data-only internal projection/value model
- open-data model + market/expert prior hybrid
- position-specific models vs one global model
- simple transparent statistical baseline vs higher-complexity ML approach

Do not assume machine learning is better than a simpler model without held-out evidence.

## Required evaluation design
Any proposed model must specify a leakage-safe historical validation plan. At minimum:
- train only on information that would have been available before the relevant historical draft date
- hold out later seasons or use rolling-origin validation
- evaluate Full-PPR outcomes and/or replacement-adjusted value consistent with the War Room use case
- compare directly against a contemporaneous expert-consensus baseline when lawful historical inputs are available
- report calibration, rank error/correlation, top-N hit/miss behavior, and meaningful downstream draft-value deltas
- separate injury/availability forecasting error from per-game performance error where possible
