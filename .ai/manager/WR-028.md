# WR-028 — Custom Ranking Engine Roadmap / Architecture Plan

TASK ID: WR-028
ROLE: Manager / Architect
STATUS: COMPLETE
DATE: 2026-09-09

## Objective
Define the staged roadmap required to turn the current historical custom-ranking research into a technically complete War Room-owned fantasy draft ranking engine while preserving the frozen WR-021 / WR-023 prospective test and existing FantasyPros production authority.

## Why needed
The project now has enough evidence to stop treating custom ranking as a sequence of disconnected experiments.

Verified evidence already supports:
- a useful returning-player mean projection signal;
- position-specific positive and downside-warning features;
- a clean distinction between player-value modeling and ESPN market timing;
- a frozen 2026 prospective test;
- evidence that a universal risk penalty is too blunt;
- evidence that the richer rookie model does not yet beat the transparent rookie prior.

The remaining work should therefore follow a planned engine architecture with explicit gates instead of ad hoc model tuning.

## Current verified evidence base
- WR-018: initial open-data experiment — MORE EVIDENCE NEEDED.
- WR-021: context-enriched returning-player signal — PROMISING / research only.
- WR-023: immutable 2026 prospective evaluation protocol accepted.
- WR-025: historical ranking-signal study — MORE EVIDENCE NEEDED, but returning-player Ridge mean projection improved pooled MAE by 6.61% with favorable player-clustered uncertainty.
- WR-025 universal risk overlay failed rank stability because WR and TE rank MAE regressed >5%.
- WR-025 rookie Ridge remained worse than the transparent rookie prior.
- WR-027 is active to determine position-specific risk architecture.
- WR-029 is planned to test advanced usage, OL, coaching/scheme, snap/route, depth/competition and other context families before the returning-player v1 specification is frozen.

## Architectural principle
Separate the custom ranking engine into independent layers:

1. expected performance;
2. opportunity / role;
3. availability;
4. downside / breakout / uncertainty;
5. rookie handling;
6. season-total projection;
7. positional replacement value;
8. cross-position draft value;
9. tiers / explanation / warning output;
10. market timing as a separate ESPN-derived signal.

Do not collapse these into one opaque score unless later evidence specifically justifies it.

## Definition of completion

### Research-complete
Historical methods, inputs, source rights, validation and failure modes are understood well enough to select a fixed engine architecture.

### Engine-complete
A reproducible custom engine can generate QB/RB/WR/TE preseason projections, risk outputs, availability estimates, positional values, overall ranks, position ranks, tiers and explanations from point-in-time preseason inputs.

### Shadow-ready
The engine is integrated into the War Room as a non-authoritative shadow path with deterministic generation, versioning, reproducibility and QA. FantasyPros remains production ranking authority.

### Production-candidate
The engine has passed all historical architecture gates plus the frozen WR-023 prospective gate and Manager has separately authorized a production-ranking milestone.

### Production-authoritative
Requires a separate Manager decision, Builder implementation, independent QA/audit and explicit WR-D001 replacement or amendment. No current task authorizes this state.

### Phase 1.5 — Advanced context feature enrichment — PLANNED
Task: WR-029.
Owner: R&D after WR-027 Manager disposition.

Goal:
Test whether richer preseason-known context materially improves the returning-player model before its v1 specification is frozen.

Priority families:
- snap percentage / offensive participation;
- pass-play or route participation and true YPRR only where exact route denominators are defensible;
- targets per route / carries per snap / red-zone and goal-line role;
- advanced receiving/rushing/QB efficiency;
- offensive-line environment using reproducible non-proprietary proxies;
- team pace, play volume, pass/run tendency and offensive efficiency;
- coaching / offensive coordinator / play-caller continuity and scheme tendencies where rights/coverage permit;
- depth-chart / teammate competition / vacated opportunity using true point-in-time data;
- position-specific age/experience/physical context;
- maintainable availability context;
- schedule/opponent context only as secondary evidence.

Gate:
Each feature family is classified `CORE MODEL SUPPORTED`, `WARNING / EXPLANATION ONLY`, `INSUFFICIENT EVIDENCE`, or `EXCLUDED — RIGHTS / POINT-IN-TIME / COVERAGE`.

No feature enters v1 merely because retrospective fit improves. It must provide stable chronological out-of-sample value without material positional regression and must have maintainable source rights/point-in-time semantics.

### Phase 2 — Returning-player projection specification freeze — PLANNED
Owner: R&D first; Manager disposition required.

Goal:
Select the fixed v1 returning-player projection specification after WR-027 and WR-029.

Required outputs:
- final feature set by position;
- preprocessing / scaling / missing-data rules;
- model family and hyperparameters;
- expected PPR/game projection;
- uncertainty / interval method if defensible;
- robust-tail treatment if supported by WR-027;
- admitted advanced context families from WR-029;
- reproducible historical rolling-origin metrics;
- frozen historical benchmark table.

Minimum evidence expectation:
- materially better pooled MAE than previous-season PPR/game baseline;
- favorable repeated-player-aware uncertainty;
- Spearman non-worse;
- no hidden major positional regression;
- no post-hoc feature selection on the same final evaluation folds without being labeled exploratory.

### Phase 3 — Rookie engine v1 — PLANNED
Owner: R&D.

Goal:
Create a defensible rookie ranking method independent of the returning-player model.

Starting default:
The transparent position + draft-capital bucket prior remains the benchmark because WR-021/025 richer rookie Ridge did not beat it.

Required investigation:
- draft position / round / capital;
- position-specific historical priors;
- age/experience where point-in-time valid;
- rights-clean college production or athletic inputs only if exact licensing and historical point-in-time semantics are established;
- uncertainty bands due sparse history.

Gate:
A challenger replaces the transparent rookie prior only if it improves chronological historical performance without unstable positional regressions. Otherwise v1 uses the transparent prior and explicitly reports higher uncertainty.

### Phase 4 — Availability / games model — PLANNED
Owner: R&D.

Goal:
Predict recorded games / availability separately from PPR/game.

Rules:
- do not call this a medical injury model unless medical/injury data are actually admitted and validated;
- zero-game players remain part of season-total/value evaluation;
- availability must not be hidden inside PPR/game target selection.

Outputs:
- expected games;
- downside availability probability / band where defensible;
- historical MAE/calibration;
- separate returner and rookie treatment.

### Phase 5 — Season-total distribution — PLANNED
Owner: R&D.

Goal:
Combine performance and availability into expected season production and uncertainty.

Outputs:
- expected PPR/game;
- expected games;
- expected season PPR;
- conservative / median / upside ranges where defensible;
- probability-style downside/upside labels only when calibrated.

Gate:
Season-total output must outperform transparent baselines historically or remain secondary/explanatory rather than rank-driving.

### Phase 6 — Positional replacement value and cross-position draft value — PLANNED
Owner: Manager architecture + R&D evidence; Builder only after architecture approval.

Goal:
Convert projections into a fantasy-draft value system suitable for an overall board.

Required design:
- league-specific starter structure;
- replacement-level definition by position;
- FLEX treatment;
- bench-depth assumptions;
- scarcity/value-over-replacement transformation;
- no ESPN ADP in intrinsic player-value calculation;
- market timing remains separate.

Outputs:
- custom QB/RB/WR/TE positional value;
- overall custom value;
- overall custom rank;
- position rank;
- tiers based on value gaps / uncertainty, not arbitrary manual buckets.

Gate:
Historical rank/value metrics must improve or remain stable versus transparent custom baselines by position and overall. Any risk modifier retained from WR-027 must satisfy its position-specific gate.

### Phase 7 — Historical ranking replay / draft-value validation — PLANNED
Owner: R&D; Independent Auditor may later review methodology if promoted.

Goal:
Replay prior seasons as fake preseasons and test the complete engine, not just PPR/game.

Required evaluation:
- overall rank quality;
- position rank quality;
- top-N overlap / hit rate;
- value-above-replacement error;
- tier stability;
- breakout/downside calibration;
- tail misses / catastrophic over-ranks;
- season-to-season stability;
- snake-draft simulation only if its assumptions are predeclared and useful.

Historical market-cost claims remain prohibited unless a sufficiently broad lawful comparable ADP/ECR source is admitted.

## Non-goals

- changing current production ranking authority;
- changing WR-D001;
- rewriting WR-021 predictions;
- rewriting WR-023 protocol/gate;

- treating warning probabilities as causal truths;
- claiming superiority to FantasyPros without lawful/methodologically valid evidence.
