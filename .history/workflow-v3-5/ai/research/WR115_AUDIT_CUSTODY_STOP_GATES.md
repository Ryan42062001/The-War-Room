## 1. What “no local raw retention” does and does not waive

**No local original-source retention** means the future system is *not allowed to rely on Ryan/War Room keeping a local original raw `stats_player` asset as the audit reference*. This **does not** make raw-source identity, pregame point-in-time feature bytes, post-season targets or later independent reference verification optional. A *future authorized* transient read/stream/hash for permitted source ingestion may be necessary to register the reference; whether such transient caches, process memory, downloads or copies remain within Ryan's exact option-C rule and legal terms requires separate owner/Manager/security approval **before execution**. This document authorizes **none**.

Full reference-level review requires a **future legally entitled independent Auditor** to acquire exact original F27/T27/F28/T28 source bytes (or a lawful byte-identical reference copy), compare them to **independently pre-registered** source-format/encoding/hash/size/release-version/as-of metadata, and read necessary legally held *keyed* derived/forecast/target/protocol records to rederive every population and metric. Independently re-fetching “latest” rows, reserializing logically similar values or checking an author-reported hash without any reference values is **not** equivalent. A GitHub immutable release **if** enabled would protect an asset *while the release exists*; it is not a lifetime hosting guarantee or a data-license adjudication. Official documentation: https://docs.github.com/en/code-security/concepts/supply-chain-security/immutable-releases ; https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain/establish-provenance-and-integrity/prevent-release-changes ; https://docs.github.com/en/rest/releases/assets (public docs reviewed 2026-09-19). No actual nflverse release-asset metadata or bytes inspected under WR-115.

**Four distinct source roles remain mandatory:** F27 = completed-2026 regular-season prior-year source as of 2027 pregame forecast; T27 = separate post-2027 corrected target; F28 = pre-2028 as-of 2027 regular-season features (its bytes may differ from T27); T28 = separate post-2028 corrected target.
