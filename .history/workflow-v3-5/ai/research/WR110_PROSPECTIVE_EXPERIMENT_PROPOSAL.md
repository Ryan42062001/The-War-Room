## 6. Candidate **prospective** acceptance thresholds and statistical safeguards

The thresholds here are *proposed normative safety requirements*, not observations or estimates from exposed 2024–2025 data. Reusing historic WR-072/WR-095 threshold definitions **does not revise WR-101's failed result**. Manager must freeze numeric gates and the full executable formulas/row weights/missingness before future target access and obtain independent protocol audit; if the later single primary architecture warrants different justified gates, that is a **new audited version before any prospective scoring**.

| Layer | Proposed predeclared gate (candidate vs same-row primary persistence) | A priori justification / exposure control |
| --- | --- | --- |
| Pooled predictive gain | Relative MAE lift ≥ `0.005` in validation and confirmation; `(baseline MAE − candidate MAE)/baseline MAE` with strictly positive finite baseline denominator. | Inherited prior fixed modest minimum useful gain; **not** optimized to the known RB or pooled confirmation figures. This is a screening gate, not sufficient alone. |
| Pooled uncertainty | In confirmation, predeclared player-ID-cluster paired bootstrap candidate-minus-primary MAE difference: 97.5th percentile ≤ `0`; 5,000 deterministic replicates, cluster multiplicity applied to all seasons for a player, fixed sorted cluster keys and seed assigned at protocol freeze. | Null of no improvement must be excluded by a fixed one-sided 2.5% margin; repeat players are not independent rows. Future protocol must freeze all resample/quantile implementation details on synthetic fixtures. |
| Tail safety | Pooled RMSE regression ≤ `0.01`; mandatory P90/P95/P99/max absolute error and top-1%/top-5% SSE-share disclosure by position and season; do not omit catastrophic rows. | Inherited conservative 1% tail-sensitive regression ceiling; extreme feature extrapolation is an observed historical risk. Quantile/SSE diagnostics are mandatory transparency, not gates retro-fitted to known outliers. |
| Per-position point estimates | For **each** eligible QB/RB/WR/TE, relative MAE regression ≤ `0.05` on both stages; every position must have ≥ `30` evaluable target-season rows and ≥ `30` distinct player clusters in each confirmation season. | The 5% limit is the already frozen prior per-position safety budget, carried forward **unchanged**; never relaxed because RB previously missed it. 30 is prior eligible support floor, with an added cluster-support requirement to avoid overstated confidence. If underpowered, **INSUFFICIENT**, not exempted. |
| Per-position uncertainty | In confirmation, each position's paired player-cluster bootstrap **98.75th percentile upper bound** for relative MAE regression must be ≤ `0.05`, with finite positive baseline for every replicate or fail closed. | A conservative simultaneous one-sided 5% familywise guard across four predeclared positions (Bonferroni 0.05/4 = 0.0125); an aggregate pass must not mask position uncertainty. New strict prospective guard, not a claim the prior protocol used it. |
| Season stability | Confirmation mean candidate-minus-baseline seasonal MAE delta ≤ `0`; max eligible season MAE regression ≤ `0.05`; validation season regression ≤ `0.05`. Report each season/position pair even if too small for a formal cell gate. | Guards against a pooled result dominated by one season without shopping for the most favorable year. 2027 single-season validation is limited evidence and does not substitute for multi-year confirmation. |
| Rank preservation | Weighted within-position-season Spearman delta ≥ `−0.01` and weighted rank-MAE relative regression ≤ `0.02`; deterministic tie/eligible-cell/weight rules fixed. | Carries forward existing fixed ordinal safety tolerances; a “good MAE” forecast that destroys roster-relevant ordering is not accepted. |
| Secondary baselines | Confirmation relative MAE regression ≤ `0.01` against each pre-admitted, timestamp-safe secondary rate baseline, identical rows. | Avoids success versus a weak single comparator while forbidding retrospective cherry-picking of a new baseline. |
| Fallback / abstention | Unexplained/unauthorized fallbacks and lineage failures = `0`. If protocol C or another primary candidate includes intentional abstention, allow at most `0.05` of **all eligible rows per season and position**, count every abstained row as its frozen persistence prediction in *every* metric, and separately report correction-only coverage. If an arm is pure persistence, mark it CONTROL, not candidate improvement. | Five-percent is a **proposed prospective maximum non-coverage budget** for a deployable estimate, not computed from exposed results; fail closed on hidden non-coverage and require training-only abstention thresholds. Does not waive other gates. |
| Rate/availability calibration | If a distinct games/availability estimator is included, fix its target population, binary/count scoring and interval calibration/coverage/width bounds **in a separate independently audited model contract before outcomes**; rate success does not imply availability success. | A PPR/game endpoint contains no games-played probability. This report deliberately does **not** invent games-calibration numerical thresholds or authorize season-total composition; an architecture requiring them cannot execute until separately specified. |
