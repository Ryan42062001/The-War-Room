## Candidate feature families

### 1. Long-history opportunity / role — FIRST PRIORITY
Test by position:
- target share / carry share;
- targets per team dropback or pass attempt where definition is stable;
- air-yard share / aDOT / WOPR-style opportunity;
- red-zone targets/carries;
- goal-line / inside-10 / inside-5 opportunities;
- opportunity concentration, backfield split, top-two concentration / HHI-style summaries;
- third-down / two-minute opportunities only where point-in-time and PBP definitions are defensible;
- expected-opportunity / actual-minus-expected style features only after exact model/license/version verification.

### 2. Long-history efficiency and regression
Test with shrinkage / sample-size controls:
- rush EPA/success/explosive rate;
- receiving EPA/target, success, yards/target, catch rate, YAC/target, RACR-style measures where reproducible;
- first-down/conversion rates where field semantics are stable;
- TD per opportunity / expected-TD delta / red-zone conversion as regression indicators;
- QB EPA/dropback, success, CPOE only where field provenance is accepted, deep rate/aDOT;
- QB designed rushes, scrambles/dropback, red-zone rush and kneel-excluded rushing opportunity.

### 3. Team offensive environment
- pace / plays per game / situation-filtered volume;
- neutral pass rate / PROE-style residual only with frozen expectation-model version;
- team EPA/play / success / points or scoring opportunities;
- target/carry concentration;
- returning-QB continuity from lagged completed-season evidence;
- player team-change flag where cutoff-safe;
- schedule/opponent context only as secondary warning/uncertainty evidence unless stable lift is proven.

### 4. Offensive-line environment — PBP PROXIES FIRST
Prefer reproducible team-environment proxies rather than proprietary grades:
- sacks per true dropback;
- non-kneel run EPA/success;
- short-yardage and goal-to-go success;
- stuff/explosive-run rates;
- documented adjusted-line-yards-style transformation only if formula/naming is rights-safe and clearly labeled as a blended line/back/QB/scheme environment.

Do not describe these as causal OL grades.

OL continuity / returning-snap share / likely-starter experience may be explored only after separate rights and point-in-time evidence passes. They are not core dependencies by default.

### 5. Age / experience / draft capital interactions
- age at fixed preseason cutoff;
- years since rookie season;
- nonlinear position-specific age curves;
- draft-pick/round/capital with time-varying decay where justified;
- multi-year performance/opportunity trend interactions.

Preserve rookie separation.

### 6. Point-in-time depth / roster / competition
Only after a historical PIT audit:
- preseason depth rank;
- teammate competition / same-role incumbents;
- vacated targets/carries/red-zone chances;
- roster churn / new-team context;
- expected starter-QB context;
- late signings / cuts / retirements.

Never reconstruct preseason roles from target-season Week 1+ outcomes, current mutable fields or end-of-season rosters.

### 7. Coaching / staff continuity — WARNING-FIRST
Investigate HC, OC and actual play-caller change/tenure only if a rights-clean team-season corpus can be measured for coverage and as-of quality.

Before core admission, report coverage for every target season/team, interim roles, dual-role HC callers, midseason changes and source dates. OC identity must never be assumed to equal play caller.

PBP-derived prior team tendencies may enter independently of staff identity.

### 8. Short-history scheme challenger
Motion, play action, RPO, no-huddle, shotgun/pistol, personnel usage and related charted concepts may be tested only after explicit provenance/rights review and should initially be research-only because short history can reduce chronological validation depth.
