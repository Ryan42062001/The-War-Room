## Required protocol freeze
Create a research protocol that fixes all of the following before any 2026 outcome scoring:

### 1. Immutable evaluation universe
- Use the WR-021 frozen snapshot exactly as committed.
- Do not add/remove players based on 2026 performance.
- Preserve returner vs drafted-rookie classification.
- Preserve missing-GSIS / UDFA limitations.

### 2. Primary prospective hypothesis
Primary hypothesis applies to RETURNING PLAYERS ONLY:
The frozen WR-021 Ridge PPR/game prediction outperforms the frozen previous-season PPR/game baseline on 2026 outcomes.

Rookie Ridge performance is NOT part of the primary hypothesis because WR-021 did not validate it historically.
Rookie scoring must remain separate and diagnostic, with the transparent rookie baseline as the primary rookie comparator.

### 3. Outcome definitions
Predefine exact 2026 outcome data source and fields before scoring.
Prefer the same admitted rights-clean nflverse Player Summary Stats family used by WR-021.

Define:
- performance: Full-PPR points per recorded game for frozen-cohort players with >=1 recorded 2026 game;
- availability: 2026 recorded games, frozen-cohort players with no target row = 0;
- season total: total 2026 Full-PPR points, no target row = 0.

Do not substitute later injury/depth context into the frozen predictions.

### 4. Checkpoints
Predeclare:
- interim checkpoint(s), if any, as descriptive/non-decisive only;
- final regular-season checkpoint as the decisive prospective evaluation.

Interim results must not trigger model retuning, feature changes, cohort changes, or threshold changes.

### 5. Primary final evidence gate
For the returning-player Ridge model to qualify for `PROSPECTIVE SIGNAL CONFIRMED — PRODUCTION MILESTONE MAY BE CONSIDERED`, all must hold at the final 2026 regular-season evaluation:

1. pooled returning-player PPR/game MAE improves by at least 3% versus the frozen baseline;
2. paired player-level bootstrap 95% interval for `Ridge absolute error - baseline absolute error` has upper bound < 0;
3. pooled Spearman is not worse than baseline by more than 0.01;
4. at least 3 of 4 positions have non-worse MAE versus baseline, and no position is worse by more than 5%;
5. no evidence of snapshot/data contamination or post-freeze model changes.

If any condition fails, classification must be `PROSPECTIVE SIGNAL NOT CONFIRMED` or `MORE EVIDENCE NEEDED`.

Passing this gate still does NOT authorize production. It only allows the Manager to consider a separate production-milestone proposal.

### 6. Secondary metrics
Predeclare and report separately:
- RMSE
- rank MAE
- fantasy-relevant top-N overlap
- availability MAE
- season-total PPR MAE
- position-level metrics
- rookie baseline/Ridge/Boost results

Secondary metrics may explain results but cannot override a failed primary gate.

### 7. FantasyPros comparison
Do not claim shadow-model superiority to FantasyPros unless the Manager separately determines that a lawful, contemporaneous comparison using the production ranking snapshot is permitted and methodologically valid.

The protocol may preserve the production commit reference needed for a future comparison, but must not manufacture or scrape new FantasyPros historical data.

### 8. Integrity / immutability
Record hashes for:
- frozen 2026 snapshot
- protocol file
- source manifest/provenance files used for later scoring

Document that later evaluators may append outcome evidence but may not rewrite the frozen protocol or snapshot.
